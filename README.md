# مشروع كشف الكمامات باستخدام التعلم العميق
## Face Mask Detection using Deep Learning

هذا المشروع يستخدم تقنيات التعلم العميق والتعلم الآلي لكشف ما إذا كان الشخص يرتدي كمامة أم لا من خلال تحليل الصور.

### المميزات الرئيسية
- استخدام نموذج MobileNetV2 المحسن مسبقاً
- دقة عالية في كشف الكمامات
- واجهة سهلة الاستخدام
- قابل للتطوير والتخصيص

### المتطلبات
- Python 3.7+
- TensorFlow 2.x
- OpenCV
- NumPy
- Matplotlib
- PIL (Pillow)
- Scikit-learn

### التثبيت
```bash
pip install tensorflow opencv-python numpy matplotlib pillow scikit-learn
```

### الاستخدام
1. قم بتشغيل ملف `PatternProject_MaskDetection.ipynb`
2. تأكد من تثبيت جميع المكتبات المطلوبة
3. قم بتشغيل الخلايا بالترتيب

### النتائج
- دقة عالية في التصنيف
- رسوم بيانية توضيحية للأداء
- تقارير مفصلة عن النتائج
